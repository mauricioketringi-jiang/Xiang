## 连击与弱项训练

- ⚡ 极速连击默认开启，正确且反应时间不超过 1.8 秒时，显示短反馈并在 450ms 后进入下一题。
- 答错、慢反应显示详细复盘，并保留重听和下一题。
- 镜像易混题：14 ↔ 40、15 ↔ 50、115 ↔ 150、1500 ↔ 15000、24000 ↔ 240000、1.25 ↔ 12.5、4:15 ↔ 3:45，以及 8/0、5/9、2/3 等。
- 从错题池构造 A → A′ → A′ → A 的交叉训练，复盘提示包含镜像对比。词汇错题仍保留原有选择题训练。

## 音频架构与 iOS 限制

- 原生 Web Speech (`speechSynthesis`) 本地语音；不向外部音频服务请求音频，也不下载 90MB 语音模型。
- `speak()` 前先 `cancel()` 清队列，延迟 80ms，并在文本前追加句点作为软启动尝试；具体系统朗读如何解释句点取决于语音引擎。
- 正常情况下从 `utterance.onend` 开始计时；**仅在事件丢失时**执行超时保底，保底时间为推算时间，不代表真实语音结束瞬间。
- 监听 `visibilitychange`、`pageshow`，尝试恢复系统朗读及 AudioContext。
- **iPhone 真机限制**：网页无法保证完全杜绝首字吞音；无法修改硬件静音/响铃状态；英音和澳音需设备本地有对应语音。
- **底噪限制**：Web Audio 可生成独立环境电流噪声，但 Safari 无法将 `speechSynthesis` 系统语音流路由进 Web Audio Filter，因此电话模式不等于对真人声进行带通压缩。
- **口语反射**：使用浏览器 Web Speech Recognition；部分浏览器识别能力或识别服务需要联网，不保证全离线。

## 部署

完整静态文件包括 `index.html`、`manifest.webmanifest`、`sw.js`、`icons/`。可放在 GitHub Pages 或其他 HTTPS 静态站点；首次安装与离线缓存需要成功加载网页，Service Worker 才生效。

直接打开 `index.html` 可使用核心训练逻辑，但 `file://` 环境通常不支持 Service Worker 离线安装。用户数据位于浏览器的 localStorage / IndexedDB，建议更新前先在应用中导出备份。
