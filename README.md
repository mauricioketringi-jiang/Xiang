# 英语数字与专业词汇声音反射训练

GitHub Pages 网页版，支持 iPhone Safari。课程、题目生成、答题、错题与历史记录保留在 `index.html`；学习数据保存在手机浏览器本地。

## 离线系统发音

- 不再联网请求英语音频文件，不下载或运行 Piper、eSpeak 音频模型。
- 播放直接使用设备已经提供的本机英语系统语音，调用浏览器 Web Speech API（`speechSynthesis`）。
- 仅选用浏览器标记为 `localService === true` 的英语声音；如果手机没有对应本机语音，则提示不可用，不会自动回退到网络语音。
- 美音、英音和 0.8× / 1.0× / 1.2× / 1.5× 语速设置仍保留。选中口音需要设备本地已有对应语音，否则请切换口音或通过 iPhone 系统设置自行准备语音。
- 系统语音播完才启动反应计时；保留原有 10／30／50 题选择、自动判题、错题记录和备份。
- 无需在网页内下载大型语音资源，也不会在播放时请求云端语音服务。

### iPhone 响铃／静音开关

网页**不能读取、更改或打开 iPhone 的响铃模式**；使用系统语音时，需用户自己在手机上切换至响铃模式（关闭静音）。即使网页收到朗读结束事件，也不能以此证明真实扬声器已经发声。

### 不联网运行网页

`sw.js` 是离线网页缓存：需先在有网络时通过 Safari 打开网站并让 Service Worker 成功缓存首页。完成首次缓存后，可断网再次打开网站。如果 Safari 清除或回收网页缓存，需再次联网访问恢复页面。网页不包含语音下载流程；系统英语语音能否完全离线工作，取决于所选语音是否已经安装在 iPhone 本地。

## 部署与数据

- 静态网站使用 GitHub Pages，不使用 Vercel、COS、付费语音 API 或后端服务。
- 源码不包含语音音频模型，不再在 GitHub Actions 中生成在线音频。
- 个人学习记录用 `localStorage` 与 `IndexedDB` 保存；可导出和导入备份。
- 推送至 `main` 自动运行语法检查、离线语音功能模拟测试并部署网站。自动化测试使用模拟本地语音，不能替代 iPhone 真机试听。
