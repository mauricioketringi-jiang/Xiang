# 声音反射训练 · 进阶版

## 安装

解压后通过 HTTPS 静态服务器部署 `index.html`（GitHub Pages 等）。首次打开后，浏览器保留学习数据在本地存储。

## 功能

- 原有 16 个数字关卡 + 2 个专业词汇分类完全保留。
- 10 / 30 / 50 题选项、数字输入即确认，无需单独提交。
- 统计实时更新 `totalAnswered` / `totalCorrect`，并兼容原来的 `totalQuestions`。
- 极速连击默认开启；答对且反应时间 ≤ 1800 毫秒，450 毫秒后跳题；其他情况进入详尽复盘。
- 计时严格在 TTS `onend` 之后启动。口语反射从题目出现时开始计时，包含语音识别延迟。
- 纯数字键盘禁用符号；时间高亮冒号；小数/百分号高亮；航班号支持字母。
- 关卡模式限定美音、英音、澳音、多国混播以及电话/环境底噪。
- 口语反射支持浏览器原生语音识别与手动自检。
- 含移动端 PWA Meta 标签。

## 浏览器与音频限制

- **系统 TTS 无法通过 Web Audio API 接入滤波器**，电话分机模式只能模拟窄带背景电流噪音，并不能真正压缩或滤波 TTS 人声。环境底噪是实时 Web Audio 生成，与 TTS 并行播放。
- 英音、澳音须操作系统或浏览器提供对应语音；没有时不会把美音冒充为对应口音。
- SpeechRecognition 在 iOS / Android 上支持情况不同，部分浏览器实现需要网络服务。本版会显示可手动自检的按钮。
- iPhone 静音开关可能会抑制系统 TTS。网页不能自动更改响铃或静音模式。
- 口语自检结果不可等同于自动语音识别；口语反射计时包含说话及识别耗时。
