# 声音反射训练 V6 · 23 关完整版

保留 V5 全部 20 个数字关卡、3 个工业英语关卡（38 + 38 + 40 条）、成对易混镜像特训、多国口音、四种环境底噪、学习统计、极速连击及 iOS 语音恢复机制。

## V6 核心变化

- 顶部删除 COMBO 连击显示和后台计数；将训练方式改为同一行三等分：🎧 听音按键、🎙️ 看数开口、⌨️ 拼写单词。
- 拼写单词：听语音拼出**完整播报英文**（包括长数字、时间和工程词组）；第五阶段会显示中文释义。使用自研 QWERTY 键盘，**不会触发系统输入法**。忽略英文大小写、空格、连接号及标点；拼写完全正确时自动判题，450ms 后下一题。拼写内容长度达到目标长度但不匹配、或停止输入 1.8 秒，则展开错误解析。拼写键盘的“空格 / -”短按输入空格、长按 400ms 输入连字符。
- 听音按键：数字键盘固定 4 行×3 列，即 1–9、退格/0/重听，不显示清空、点号或冒号独立键。仅当标准答案包含小数点或冒号时，在输入框右侧提供对应快捷按钮；在这类题中双击/长按 0 也可输入符号。第 14 关航班号仍使用原答题框键入英数字母，确保关卡可完成。
- 两套键盘的“退格”均支持点按删除一字符、长按 400ms 清空；在实际移动端无需系统输入法即可完成拼写模式。
- 极速连击仍强制开启；非拼写模式沿用“正确且 ≤1.8 秒”的自动连击规则。反应时间从 TTS onend 或语音保底完成事件起算。

## 使用与限制

浏览器打开 `index.html` 可预览；PWA 安装、缓存离线及部分语音服务需要 HTTPS 或 localhost。Safari 系统语音可能受静音模式影响，网页无法切换手机响铃模式。Web Speech 语音识别在各平台支持不同，部分实现需要联网。第 19 关缺少地区本机音色时是近似音而非真实口音；第 20 关的合成底噪无法滤波系统 TTS 人声。学习记录存于设备本地，更新不会主动清空。
