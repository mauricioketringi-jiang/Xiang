# 声音反射训练 V9 · 23 关完整版

## 源码与运行

完整的 23 关单页应用位于 `index.html`，所有题库、判题、语音、词组、历史记录及训练模式逻辑均保留。PWA 文件为 `manifest.webmanifest`、`sw.js`、`icons/`。

直接在浏览器打开 `index.html` 可预览；部署到 HTTPS 站点后，支持 PWA 主屏幕安装和已缓存网页的离线访问。学习进度保存在浏览器本机 `localStorage` 和 `IndexedDB` 中，升级不会主动清空。

## V8：点击开始才开题

- 首次进入**课程闯关、自由练习或成对易混弱项特训**时，`session.isStarted=false`；不会播放第一题语音、激活语音识别或启动反应计时器。
- 中央待机卡片显示「请先在上方选择训练模式、倍速与题量」、选中的训练模式及 **▶ 开始训练**（200×52px）。
- 开始前可选择 **🎧 听音按键 / 🎙️ 看数开口 / ⌨️ 拼写单词** 或改变语速。键盘随模式呈现但待机禁用，避免意外提交。
- 只有用户点击「开始训练」时，才尝试解锁手机音频引擎、启动 TTS／口语识别，并正式进入第一题。反应计时保持从 TTS `onend` 开始。
- 开始后切换模式或语速，立即取消当前播放及计时，返回待机，再点击开始即以新配置**重新进行当前题**；不会重复累计答案。
- 「再练一次」重新创建题组并进入待机态；通过首页恢复训练也进入待机态。
- **题与题之间不增加待机**：听音／口语正确后 380ms 自动进入下一题，拼写确认正确后 600ms 自动进入下一题；答错时保留详细解析。

## 继承的课程与功能

20 个数字类关卡（包含分数、日期、多口音及底噪环境）＋3 个工业英语关卡；工业英语库 38 条电气词、38 条自动化词、40 条工程短句，共 116 条。保留 8 国目标口音、4 类合成环境噪声、镜像易混强化、学习统计、12 键数字布局、手动确认的全宽 QWERTY 拼写键盘、iOS 语音超时恢复逻辑、PWA 本机缓存。

## 验证及设备限制

浏览器模拟检查包括 34 项主流程与全部 23 关入场、4 种手机视口布局验证；`node --check` 检查内联 JavaScript 语法。音频发声和语音识别实际可用性仍需在 iOS／Android 真机检测；iPhone 响铃开关不能由网页修改。TTS 地区近似语音不等于真实独立国家口音。

测试代码见 `tests/test_ready_state.py`、`tests/test_all_lessons_ready.py` 和 `tests/test_question_count_v9.py`。在配备 Playwright 和 Chromium 的环境中运行即可复核。

## V9：训练题量动态切换
- 右上角由静态题号升级为 10 / 20 / 30 题下拉框，显示当前题号 / 总题数，三栏保持等宽。
- 待机选择题量立即重建队列；训练中修改题量先停止播报、计时与识别并从第 1 题重启待机。
- 数字、工业词汇、自由练习、成对易混弱项特训支持 10/20/30 题。词汇不足时分轮洗牌补齐。
- 结算页与再练一次继承本轮题量；既有累计作答历史记录不因重开本轮而回滚。
