# 声音反射训练 · 精简重构 VF

## 版本原则
- 原 23 关：20 数字关 + 3 工业词汇关（38 + 38 + 40 = 116 条），源码片段逐字一致。
- 仍保留第 24 关 Teen/Ty 最小对立体与第 25 关场景训练，总共 25 关。
- 已移除第 26–28 关 IELTS/TOEIC/BEC 考试专项，以及底层题库和所有入口。
- 特训页仅 3 卡：智能弱项（含成对易混）、自由练习、学习记录（备份与重置）。
- 基础学习页从零改为 4 组数字点读表与 4 条听音规律；取消水平测试和原学习模块。
- 原 23 关的 TTS、口语、拼写、结果复盘、自动磨耳朵以及历史数据沿用原程序。

## 项目结构
- `index.html`：完整主程序，含原 23 关题库和交互状态机
- `stage-c-data.js`：保留第 24/25 关与工程扩充题库，已移除考试扩展题
- `learn-data.js`：数字表、IPA、发音提示、例读和四大规律（独立数据）
- `learn-ui.js`：学习卡片、0.7x/1.0x 音色、点读、导航和降级
- `sw.js` / `manifest.webmanifest` / `icons/`：GitHub Pages PWA 缓存与图标
- `独立单文件网页版.html`：全部 JS 已内嵌，可单独下载或部署
- `test_release.py`：源代码完整性与 Playwright 手机模拟回归
- `测试报告.md`：具体检查结论

## 语音
除第 19 关保留原 8 国口音逻辑外，其他模式沿用 en-US 优先女性音色。学习点读固定 en-US，语速可独立选 0.7x/1.0x。
设备可能没有命名的女性 TTS 音色，实际发音、静音开关、麦克风以及锁屏播放需 iPhone Safari 真机验证。

## 数据与升级
保留原有 `voice_reflex_app_v1` 本机学习记录。新的学习页点读速度保存在 `voice_reflex_learn_rate_v2`。
清空学习记录会同时清除这一新设置。应用运行完全在浏览器中，不上传练习数据。

`pages.yml` 为本次 GitHub Actions 部署工作流，正式发布复制到 `.github/workflows/pages.yml`。
