# 声音反射训练 · VF 版本 V3 · 基础学习升级

## 核心变化
1. 修复“03 · 大数单位”数字列折行：所有数字强制不换行；10,000～1,000,000,000 使用独立绿色数字徽章，字体自适应 15～18px；补齐 ten thousand 例读条。
2. 补齐“05 · 电工电气与自动化核心词”：第 21 关 38 条＋第 22 关 38 条，含英文、沿用原始 IPA、中文和可点读现场例句。
3. 补齐“06 · 高频工程短句与句型”：第 23 关原 40 句，含中文与核心词提示；全文可点击点读。每组初始显示 12 条，点击“显示更多”可查看全部。
4. 0.7x/1.0x 点读速度及章节导航组合成吸顶条；模块 01～06 和听音规律 1～3 底部均有相应关卡直达按钮，进入待机页而非自动开播。

## 完整性承诺与校验
- 原始 23 关的 `numericLessons` 原始定义以及第 21～23 关工业词库代码段，与已发布 VF 源码按 SHA-256 字节级校验一致。
- 现有 25 关（原 23 关＋最小对立体＋场景听力）均保留。
- `learn-data.js` 从原 116 个工程词条逐条生成学习数据，原英文、中文、IPA 与原课程条目完全一致。例句沿用先前 E 版本独立学习词典。
- 部分历史 IPA 写法不规范，学习数据 `check:true` 表示有待权威词典人工核对，不代表已人工验证正确。
- 页面和课程原有 `localStorage` 数据保持兼容，本次不主动清除数据。

## 文件说明
- `index.html`：正式多文件 GitHub Pages 入口；引用 `stage-c-data.js`、`learn-data.js`、`learn-ui.js`。
- `learn-data.js`：数字、规律和独立的工业学习数据，共 116 条工业词句。
- `learn-ui.js`：点读、悬浮跳转、分页、学完即练。
- `stage-c-data.js`：阶段 C 保留的两个专项关卡与其它题库。
- `sw.js`：PWA 离线缓存（本版缓存名已升级为 `voice-reflex-advanced-stage-vf-v3`）。
- `manifest.webmanifest`、`icons/`：PWA 配置与图标。
- `独立单文件网页版.html`：所有题库和 JS 内嵌，单文件可预览/部署；本地文件协议下 PWA 无法注册。
- `test_vf_upgrade.py`：Python + Playwright Chromium 320/375/390/430px 回归测试。
- `原始23关完整性校验.json`：原版 23 关代码片段 SHA-256 记录。

## 测试说明
在装有 Chromium 和 Python Playwright 的电脑运行 `python test_vf_upgrade.py`。脚本不依赖下载已发布的旧源码，校验包内基线 SHA。

iPhone Safari 的真实 TTS 音色、静音开关及麦克风兼容性，需要真机检查；模拟测试不构成对所有 iOS 系统版本的保证。
