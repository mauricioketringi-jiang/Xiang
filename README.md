# 声音反射训练 · 版本 E

基于阶段 D 28 关版本升级。原始 23 关、阶段 C 的 5 关及第 21–23 关原 116 个工业词条保持完整。

## 项目结构
- index.html：主网页及课程、练习、复盘。
- stage-c-data.js：阶段 C 扩展题库。
- learn-data.js：基础学习 5 模块、10 题水平测、116 条原工业词和例句。
- learn-ui.js：基础学习 UI、点读、水平测试、词典搜索分页与手动自检。
- sw.js、manifest.webmanifest、icons/：PWA 资源。
- standalone.html：完整单文件网页独立下载版。

## P0 固定语音
仅 19 关（八国随机口音）保留口音变化。其他所有模式固定 en-US，优先 Samantha、Ava、Allison、Joelle、Google US English；设备没有明确女性语音时使用首个 en-US 音色，无法保证性别。删除音色随机与速率抖动。学习页可独立使用 0.6x 或 1.0x。

## 学习
三栏导航：基础学习、课程闯关、特训与错题台。包含入门导览、两周打卡、10 题水平测、发音对比、数字进位、年份电话时间工业量纲、116 条原词库、现场例句、词典拼读和自检。进度继续使用原存储结构。

## 核验声明
原工业词库的 IPA 部分不规范；学习数据保留原 IPA 并将 116 项 check:true 标记为待词典人工核对。第 22 关含 18 条分类未定项，数据内 categoryCheck:true，仍保持原归属。请参考下载包内“工业词库_116条待核对.csv”与“分类待确认_18条.md”。

iPhone Safari 上系统安装音色、语音识别、后台/锁屏音频均由设备及浏览器实际支持能力决定。
