# 声音反射训练 V5 — 23 关

20 个完整数字关卡 + 3 个工业英语专项关卡：电工与电气工程 38 词、自动化与智能控制 38 词、工程短句 40 条。原有 20 个数字题型和镜像特训逻辑完整保留。

## 训练方式

- 极速连击强制开启：回答正确、非提前提交、反应时间 ≤ 1.8 秒，450ms 后自动切下一题。
- 顶部三等分：口音/环境状态、语速、题号；第二行听音按键和看数开口。
- 数字键盘始终 3×5：1~9、.、0、:；清空、退格、重听。
- 第 14 关航班号/邮编需要字母，点击答题框调出系统键盘，不显示 ABC 键。
- 第 12 关百分号由程序根据题目答案自动处理；无需输入 %。
- 第 19 关在 8 个英语区域代码中随机抽取；缺少对应本地语音时，以已有英语音色近似播报，并标明该情况。**音高和语速变化不等于真实地方口音**。
- 第 20 关在四种 Web Audio 合成背景音之间随机选择；只能叠加环境底噪，不能对操作系统 TTS 人声做真正的电话带宽处理。
- 管理区只保留镜像弱项特训、自由练习器、学习记录与重置。学习状态仍在设备本地存储。

## 使用方法

用浏览器打开 index.html 可查看界面；完整的 PWA 离线缓存与语音麦克风功能需要 HTTPS 或 localhost 运行。可部署到 GitHub Pages，依照 Safari/Chrome 权限使用。

- **Web Speech 识别兼容性：** iOS、Android 浏览器支持情况不同，某些识别服务需要联网。
- **iPhone 无声情况：** 本地系统语音可能受静音开关和语音包安装状态影响，网页无法切换手机响铃模式。
- **学习数据：** V5 默认不会清除旧学习进度；被移除的旧 AI/医学课程不会出现在新统计中。用户主动点“重置全部学习数据”会清空记录，请谨慎操作。
