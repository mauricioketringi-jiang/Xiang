# 英语数字与专业词汇声音反射训练

单页网页，部署在 GitHub Pages。课程、题目生成、练习记录和用户界面集中在 `index.html`；训练记录保存在浏览器本地。

## 在线语音模式

不再要求 iPhone 首次下载约 90MB 的 Piper 语音模型。

- 发音所需的短音频素材由 GitHub Actions 使用 eSpeak NG 在部署阶段生成，上传至现有的 GitHub Pages 网站。
- 进入练习后，网页只请求本题需要的英语词语音频，在浏览器内拼成 WAV 后通过 HTML5 Audio 播放。
- 单次请求的素材很小；浏览器可缓存访问过的素材。**首次使用必须联网**，不需要单独点击下载模型。
- 美音 / 英音：`en-US`、`en-GB`；语速：0.8×、1.0×、1.2×、1.5×。
- 发音结束事件开启反应计时；保留数字自动判题、错题记录和学习备份。
- 如浏览器自动播放被阻止，显示“点击播放英语发音”按钮。
- 已有的系统朗读仅作为手动备用；若 iPhone 静音开关开启，系统朗读仍可能无声。

**质量限制**：eSpeak NG 的预生成音频是离线、偏机械的合成音，并非此前 Piper 模型的自然音色；逐词拼接的句子在停顿与连读方面存在差异。内置数字词语和 16 个示例专业词的发音已准备；导入的自定义词汇如果没有对应词语音频，网页会明确提示缺少该词的在线发音。后续若提供既有 CloudBase 音频的 HTTPS 链接或文件索引，可替换相应音频，不需要腾讯云 COS。

## 数据与部署

网页源代码不包含 API 密钥和付费 TTS 接口；语音素材由当前 GitHub Pages 提供，不需要新服务器、Vercel 或 COS。

本地历史记录放在 `localStorage` 与 `IndexedDB` 中。可以导出/导入 JSON 学习备份。

推送到 `main` 分支后，`.github/workflows/pages.yml` 先执行 JavaScript 检查与在线音频生成，再自动发布网站；`.github/workflows/audio-smoke.yml` 在浏览器中验证题量选择、英语发音与自动判题。正式 iOS 静音模式下有声仍须用 iPhone 真机验证。
